# 对标拆剧

仅在路径 A（甲方要求对标）时加载。

- 只依据真实看过、听过或核过的材料拆解。官网简介不能当成已拆剧情。
- 能核到的写清；后段或结局查不到，明确标注「未核」，不要用我方原创走向冒充原剧。第三方拆解、剧评或二手摘要先标「未核」，拿到原片后再核对。
- 学的是冲突、人物关系、情绪回合、钩子连接，不是照搬对白、超能力或具体事件链。能拍、能验证的揭穿办法优先。
- 若交稿需要「对标原剧框架」，与我方原创大纲分开写；前面可保留对标剧名和题材标签。不要写入音频已取得、核到第几集等内部过程废话。
- 材料不足就停，列出缺什么，等补齐再往下写。

## 拆什么：借骨架，换血肉

框架不是「讲了什么故事」，而是「这故事靠什么成立、能一直追下去」。可用下面六层问法检查，不要把某一题材的设定硬加到另一本上：

1. **发动机**：全剧靠什么转？换掉它，就不再是这部剧。
2. **权力结构**：谁压谁、谁制约谁，对手分几层、如何逐层剥开。
3. **有限筹码 / 金手指**：怎么破局；限制、代价、暴露风险是什么。没有代价的金手指，中后段危机立不住。
4. **冲突循环**：每集靠什么不一样（轮换的任务、交易、规则或对峙），而不是换汤不换药地重复辱骂。
5. **大结构 / 方向**：交付范围内怎么分段，情感或权力位置如何推进。
6. **钩子承接**：每集怎么留人，集与集怎么接上。

借这六层骨架，事件、人物、对白和道具全部重做。把游戏系统或血脉硬搬到现代都市题材，就是用错层。

## 拆完再写三句内部底稿

这些只作工作笔记，不进交稿格式（交稿大纲是否加阶段标签，跟甲方）：

- **爆因假设**：谁压谁、靠什么升级、何时换挡（换场景、换对手或换节奏）。道具只记它对矛盾的作用，不记桥段本身。
- **分幕目标**：在全剧路径和逐集表之间，每幕写一句「把 / 让 X 从 A 推到 B」。连续两幕关系位置（谁压谁、谁护谁、谁求谁）没变，要说得出理由。
- **知识账**：观众、主角、反派各在何时知道同一件事。逐集可另记本集情绪、埋点与回收集号，用来看换挡和兑付，不要把钩子库标签机械轮换当成方法。
