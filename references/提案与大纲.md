# 提案与大纲

- 写清题材、一句话故事、核心冲突、人物关系、卖点，以及卖点如何在交付集数内兑现。
- 路径 A：对标框架与原创大纲分开；原创要像对标的类型和情绪，但不是抄袭。
- 路径 B：不写对标剧名或原剧情节，按甲方题材或梗概立项。
- 大纲覆盖交付范围；若甲方只要前 N 集正文，仍要让这 N 集自身完整可读，不要把全部高潮留在未写部分。
- 先确认提案和大纲，再写人物和正文。已确认的核心设定不擅自改。

## 写之前先问清观看任务

先写清：这一阶段观众在等哪项关系或价值判断被反转。专业事件、调查线、案件里程碑都服务于这笔期待，不能用一条新调查线替代尚未兑现的情感承诺。

分集取舍先问这场戏是否服务该期待。重复攻防必须增加筹码、风险、公众知情或关系变化；把一集拆成两集，不自动等于节奏变好。

以上取舍方法用来检查结构；先婚后案、延迟调查按当次题材取舍，不是每种题材都要套用。

## 内部先过一遍再写交稿大纲

交稿形态跟甲方（宁过稿常见的是连贯叙述，不加阶段集数标签）。下面只作内部检查，不自动写进交稿：

- 每幕核心目标写成「从 A 到 B」，幕与幕的关系位置要变。
- 对手随主角升级；保护、外援、金手指要有限制或代价，并准备在中后段兑现成痛或选择。
- 关键感情转折准备落在不可撤回的可见行动上（真签字、离开、撕掉协议），口头表态通常还撑不起转折。
- 配角各写一句功能；主要人物各写一句弧光终点。写不出，说明还没定。
- 开场承诺与交付范围内的兑现对得上；开放线单独标明，不补脑。
