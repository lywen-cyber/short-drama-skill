# 连续性追踪

用来避免人名、时间、知情和钩子在集与集之间对不上。项目里另建 `continuity.md`，每写完一集就更新，不要等全部写完再补。本文件是模板和方法，可被 brief 覆盖。

`/outline` 时把分集目录的「钩子类型」「兑现类型」两栏填上，便于 `/review` 发现连续多集只用同一类钩子、或兑现方式重复。钩子类型仍按 `references/钩子与卡点.md` 的分类来写（悬念、反转、情绪、信息、危机等），不要把标签机械轮换当成写法。

审查时对照本文、`continuity.md` 和分集目录，不必把本追踪表打进对外交稿。

## 项目文件模板

复制到当前项目的 `continuity.md` 后填写。交付范围之外的事实不要提前编造。

```markdown
# 连续性追踪

## 人名与称呼

| 正文短名 | 身份 | 别名 / 称谓 | 首次出场集 |
|----------|------|-------------|------------|
|  |  |  |  |

## 时间线

| 时点（相对或日期） | 事实 | 出现集 |
|--------------------|------|--------|
|  |  |  |

## 谁知道什么

| 信息 | 观众 | 主角 | 对手 | 其他关键人物 | 首次揭示集 |
|------|------|------|------|--------------|------------|
|  |  |  |  |  |  |

## 钩子：还开 / 已兑现

| 钩子 | 抛出集 | 状态（还开 / 已兑现 / 部分兑现） | 兑现或转化集 | 说明 |
|------|--------|----------------------------------|--------------|------|
|  |  |  |  |  |
```

## 使用注意

- 人名以 `characters.md` 和正文短名为准；中途改名先改小传，再回查已写各集和本表。
- 「谁知道什么」只记已经在正文里被看见、听见或读到的信息，不记作者计划。
- 钩子从「还开」改为「已兑现」时，在分集目录的兑现类型栏也留下对应记录，避免同一套打脸连用却不加码。
- 教学示例的填写形状见 `examples/授权示范/continuity.md`（仅第 1 集）。
