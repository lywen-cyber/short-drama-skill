# 甲方反馈翻译

甲方意见常常很含糊。下表把常见说法翻成具体改法，`/revise` 时先对表，再动正文。改完仍按 `references/审查清单.md` 和审稿编辑复审。表里是常见含义，不是唯一含义；拿不准时，问甲方一句「是哪一场、哪一句」，比猜着改更省事。

以后每收到一条新意见，先记进项目的 `过稿反馈.md`（模板见 `references/过稿反馈.md`）；同一说法出现两次以上，再补进本表。

| 甲方说 | 通常意思 | 具体改法 |
|--------|----------|----------|
| 不够爽 | 兑现前压得不够，或兑现太小、太虚 | 兑现前把羞辱写得更具体、更当众；兑现要打在反派刚说出口的那句误判上，并写出围观或对手的反应 |
| 节奏慢 | 一整场里权力关系没变 | 删铺垫；每一场至少加一条新信息或新压力；用 `scripts/positions.py` 查第一次冲突是否落在前半之后 |
| 人物立不住 | 主角在反应，不在选择 | 每集给主角一个主动做出的选择，并让这个选择有代价 |
| 没有记忆点 | 没有标志性台词、画面或习惯 | 给主角一个反复出现的视觉细节或口头禅，在关键处回扣 |
| 看不懂 / 太专业 | 输赢要靠术语或文件才能看懂 | 把专业信息换成金额、时限、谁握着筹码、输了会怎样；见 `references/爽点.md` |
| 女主太弱 / 太圣母 | 她挨打不还手，或还手没有后果 | 受压之后必须有一次可见行动；让对手为此付出可见代价 |
| 反派太蠢 | 反派没动机，或输得太容易 | 给反派说得通的私利和一次真正得手；让他输在自己的误判上 |
| 感情线不甜 / 没有张力 | 两人没有不对等的权力，或没有身体距离的变化 | 设计一个不得不靠近的处境；让强势一方第一次为对方让步 |
| 钩子弱 / 留不住人 | 集尾停在流程、约定或已知答案上 | 集尾改停在未答的选择、未说完的话或身份反转上；见 `references/钩子与卡点.md` |
| 素材不够 / 不好投 | 前几集剪不出 15–30 秒能单独看懂的片段 | 第 1–3 集各写一个耳光、揭露、身份反转或当众翻盘，在分集目录「素材点」栏标出 |
| 太水 / 字数虚 | 动作描写和过渡多，戏少 | 删掉不推进的动作和重复反应；字数不够时补冲突，不补描写 |
| 尺度不行 | 平台或投放过不去 | 按 brief 和审查清单的合规提醒核暴力、未成年人、性暗示等，改成留白或切镜 |
