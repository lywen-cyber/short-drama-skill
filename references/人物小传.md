# 人物小传

- 每个主要人物写清身份、欲望、与他人的冲突、在故事里承担的功能。
- 性格来自处境中的选择、说话方式和相互影响，不是统一加狠话、冷笑或怒吼。紧张与主动、痛苦与反制可以并存。
- 反派要有动机，要可恨，并按篇幅安排对手升级，不要一上来就堆四层却在短交付里兑不完。细则见 `references/反派.md`。
- 配角各有功能（施压、传关键信息、把主角压着的心思挤出来、作反面样本等）。删掉后压力和信息都不断的，考虑合并。
- 金手指、外援、被保护都要写清限制、代价或暴露风险。
- 可视信息（气质、年龄阶段、服装变化等）按当次 brief 需要写，并与正文一致。没有「性格」标题不等于没写性格；不得无依据补设定，也不把精确五官身高当成所有项目的硬要求。
- 海外稿：译名选目标读者好记的短名；全名放文头介绍和小传，正文用短名或称谓，除非证件、告示等必须写全名。具体规则以当次 brief 为准。
- 正文出场与小传一致；中途改人物须先改小传并回查已写各集。
- 口吻按人物分化：强者对外可以有威慑，对内不必同一副面孔；不要写成人人同声。
- 公开支持或外援到位，不自动取消主角自己必须完成的关键行动。人设与尺度若中途改动，要单列核对已写各集。

小传版式跟甲方样例。常见栏位有「身份 / 年龄 / 外貌 / 性格 / 背景」，那是样本写法，不是所有订单的必填栏。文件样子见 `examples/示例项目/characters.md`。
