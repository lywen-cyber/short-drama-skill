# 示例项目：分集目录

> **教学示例，不是当次订单。** 只演示交付范围内「一行一集」的排法。

先通读目录再写正文。栏位与 `SKILL.md` 的 `/outline` 一致：集｜本集任务｜上集钩子如何接住｜本集集尾钩子｜钩子类型｜兑现类型。集标题若甲方要，写在「集」栏。本集是否为关键集或卡点集，写进「本集任务」。钩子能否接上，在目录阶段就要能看出来。钩子类型按 `references/钩子与卡点.md` 填写，供审查发现重复，不要机械轮换标签。默认 8 集的参考弧线见 `references/节奏.md`，可被 brief 覆盖。人名、时间线、知情和未关闭钩子另记在项目的 `continuity.md`，模板见 `references/连续性追踪.md`。
