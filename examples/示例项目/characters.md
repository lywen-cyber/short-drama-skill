# 示例项目：人物小传

> **教学示例，不是当次订单。** 只展示栏位。具体人物按已确认大纲写；不要把样本剧本里的人名或经历填到这里练习。

小传版式跟甲方。下面是常见写法：先写功能所需的身份、欲望、冲突，再按需要补年龄、可视信息和口吻。没有某栏不等于必缺。

## 人物 A（主角）

- 身份：【职业 / 处境，一句话】
- 欲望：【这阶段最想做成或保住的事】
- 与他人的冲突：【谁在阻止，用什么压】
- 在故事里的功能：【观众为什么站在这个人这边】
- 性格与选择方式：【受压时先怎么做，不是一串形容词】
- 限制或代价：【金手指、靠山、底牌各有什么限制】
- 可视信息（按 brief 需要）：【气质、阶段感；不编精确五官身高充数】
- 海外稿译名：【正文短名】；全名仅用于文头 / 小传 / 证件告示

## 人物 B（主要对手）

- 身份 / 欲望 / 冲突 / 功能：【 】
- 为什么做、靠什么做、为什么不更早把主角彻底除掉：【 】
- 错误确信（若有）：【他以为什么是对的，后续将打在哪一句判断上】

## 人物 C（关键第三方 / 配角）

- 功能一句：【施压 / 传递关键信息 / 公开承认主角价值 / ……】
- 删掉后压力或信息是否还在：【若都还在，考虑合并】

关系：用几句写清谁制约谁。改人物须先改本文件，再回查已写各集。
