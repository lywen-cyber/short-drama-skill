# 示例说明

这里有教学用的最小项目骨架，以及改前改后的短对照。骨架只展示文件长什么样；对照只示范写法手感。都不是当次订单，也不是可交正文。

不要把本目录的占位文字或对照情节当成可交稿件，也不要照抄示例里的情节或人名。对照样本时，只读本包 `examples/`；执行写作时仍先读根目录 `SKILL.md`，再按阶段加载 `references/`。口径优先级见 `SKILL.md`。

## 这个示例里有什么

| 文件 | 对应阶段 | 作用 |
|------|----------|------|
| `改前改后.md` | `/episode`、`/review` | 去小说化、集尾、错误确信、关键转折链、海外称谓的改前改后短对照 |
| `示例项目/brief.md` | `/brief` | 演示必填字段怎么填（假想的宁过稿要求填法） |
| `示例项目/creative-plan.md` | `/plan` | 演示提案与大纲要写清哪些块 |
| `示例项目/characters.md` | `/characters` | 演示人物小传栏位 |
| `示例项目/episode-directory.md` | `/outline` | 演示分集目录一行一条 |
| `示例项目/episodes/第01集.md` | `/episode` | 演示场头、人物、△、对白的排法；正文是占位。分集统一为 `episodes/第NN集.md`（两位编号） |

本包可独立使用。对照用的原文在单独的私有语料库，仅授权协作者可看。
